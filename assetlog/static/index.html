아직 기록이 없어요

평가액이 두 번 이상 쌓이면 자산 증식 속도와 배당 기여를 보여 드려요.

  1. 입력 탭에서 계좌를 추가하세요. 증권사 동기화를 쓰면 계좌가 자동으로 생겨요.
  2. .env에 KIS_ · KB_ · TOSS_ API 키를 넣고 동기화를 누르거나, 거래내역 파일을 가져오세요.
  3. 하나은행 DC처럼 API가 없는 계좌는 평가액과 부담금 입금을 직접 입력하세요.

평가액과 원금

두 선 사이가 투자로 불어난 돈이에요.

계좌

연도별 수익률

막대 = 가격 변동 + 배당 기여, 점 = 자산 증가율(입금 포함)

월별 배당금

최근 24개월, 세후 입금액

보유

PC가 마지막으로 올린 잔고예요. 새로 조회하려면 PC에서 새로고침하세요.

검토

자동으로 분류하지 못한 거래예요. 원금이 들어오고 나간 것인지(입금·출금), 배당·이자인지, 매매·환전 같은 계좌 안의 거래인지 골라 주세요. 다른 증권사에서 옮겨 온 주식(타사대체 입고·출고)만 그날 평가금액을 금액에 넣고 입금·출금으로 분류하세요. 공모주·무상증자처럼 이 계좌 돈으로 생긴 입고는 계좌 안 거래예요.

입력

증권사 동기화

.env에 설정한 증권사 API로 잔고와 거래내역을 가져와요.

    평가액 직접 입력

    DC 퇴직연금 적립금이나 과거 연말 잔고를 채울 때 쓰세요. 직접 입력한 같은 날짜는 덮어써요.

      금현물 보유 입력

      증권사 앱의 금현물 잔고에 보이는 보유량과 매입금액 합계를 넣으세요. 늘어난 만큼은 매수로 기록하고, 평가액은 매일 KRX 금 시세로 계산해요.

      거래 직접 입력

      DC 부담금 입금처럼 파일이나 API로 들어오지 않는 입출금을 적어요. 출금은 양수로 적어도 자동으로 −가 붙어요.

      파일 가져오기

      증권사에서 내려받은 거래내역 파일을 올리세요. 같은 파일을 다시 올려도 중복되지 않아요.
